# DM Sans

Self-hosted variable fonts, weights 400–700, normal style. Downloaded from Google Fonts on 2026-10-12. DM Sans was already used by the original hotel interface; the planner uses it for both headings and body text.

- Latin: https://fonts.gstatic.com/s/dmsans/v17/rP2Yp2ywxg089UriI5-g4vlH9VoD8Cmcqbu0-K4.woff2
- Latin extended: https://fonts.gstatic.com/s/dmsans/v17/rP2Yp2ywxg089UriI5-g4vlH9VoD8Cmcqbu6-K6h9Q.woff2
- Source stylesheet: https://fonts.googleapis.com/css2?family=DM+Sans:wght@400..700&display=swap
- License: SIL Open Font License 1.1; see OFL.txt, sourced from https://raw.githubusercontent.com/google/fonts/main/ofl/dmsans/OFL.txt

The planner loads these from its own origin. No third-party font request is needed.
